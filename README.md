# Top Down Shooter
#
## Раздел 1. Концепция проекта
Проект предназначен для игры на ПК, для лиц любого возраста и любого пола.

Похожие игры: Doorkickers, Brotato

В коде присутствует классы игрока, оружия, врагов, предметов игрового уровня, проджектайлов.

Игрок может: ходить, стрелять, подбирать оружие и патроны.
Враги преследуют игрока, когда замечают, бегут за ним и атакуют.

Используются стандартные модельки игрока, модели зомби с миксамо и оружие из магазина.

Игрок хранит в себе ссылку на оружие. Параметры оружия берутся из таблицы.
#


## Раздел 2. Проектирование
Игрок: ```Character, CharacterHealthComponent, InventoryComponent```

Враги: ```EnemyCharacter, HealthComponent```

Перечисления для ходьбы и оружий: ```EMovementState, EWeaponType```

Структура со скоростями передвижения персонажа: ```FCharacterSpeed```

Структура с информацией о проджектайле: ```FProjectileInfo```

Структура для величины отдачи при разных режимах ходьбы: ```FWeaponDispersion```

Структура для анимаций оружия и персонажа: ```FAnimationWeaponInfo```

Структура с информацией о выбрасывании магазина: ```FDropMeshInfo```

Структура с информацией об оружии: ```FWeaponInfo```

Структура с дополнительной информации об оружии (патроны): ```FAdditionalWeaponInfo```

Структуры для работы с виджетами: ```FWeaponSlot, FAmmoSlot```

Структура для оружия, лежащего на земле: ```FDropItem```

Класс со статичными функциями для работы с эффектами: ```UTypes```

Классы для работы с оружием и управления игроком ```GameMode, PlayerController```

Интерфейс для работы с эффектами для разных поверхностей: ```ITPS_IGameActor```

Класс эффекта: ```UTPS_StateEffect```

Класс объекта окружния: ```EnvironmentStructure```

Класс оружия: ```AWeaponDefault```

Классы проджектайлов: ```ProjectileDefault``` - обычный патрон; ```ProjectileDefault_Grenade``` - бомба с таймером до взрыва


### Репликация:
```GameInstance, GameSession``` - только на сервере

```PlayerState, PlayerPawn``` - сервер и клиенты

```UserWidget``` - только на клиентах

```PlayerController``` - у каждого клиента свой


## Раздел 5. Оценка результатов
Учебный проект выполнен со своими особенностями, добавляющими сложности и необычности в игру, такие как:

- Клиент может перезапустить уровень
- При смерти одного игрока, второй тоже умирает. (интересная особенность =))
- Таймер на клиенте бежит даже при смерти всех врагов на карте (крутая особенность, чтобы клиент мог смотреть, как утекает драгоценное время)
- На клиенте и сервере разный дроп с монстров (можно соревноваться, кому выпала пушка лучше)
- При перезапуске уровня интерфейс клиента пропадает (это такая внутриигровая шутка)
- При паузе на сервере, клиент все еще может бегать и собирать оружие (еще одна интересная особенность)
- Также при победе персонаж сервера продолжает перемещаться (смешно выглядит)

В целом, проект получился таким, каким и задумывался.
